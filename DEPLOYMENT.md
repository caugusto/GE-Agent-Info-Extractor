# GE Agent Extractor Deployment Guide

This guide provides step-by-step instructions for deploying the **GE Agent Extractor** locally and in Google Cloud (as a **Cloud Run Job** triggered every 4 hours by **Cloud Scheduler**).

---

## 🔒 Security & Architecture Overview

> [!IMPORTANT]
> - **Private Batch Container (`Cloud Run Job`)**: Deployed as a **Cloud Run Job** rather than a web service. Cloud Run Jobs run to completion as isolated batch tasks and **do NOT open any HTTP ingress ports or accept incoming network traffic**.
> - **Private Scheduler Trigger**: The **Cloud Scheduler** job communicates directly with the internal Google Cloud Run API via IAM OAuth authentication (`OIDC` bearer tokens generated by `sa-ge-agent-extractor`).
> - **Least Privilege IAM Service Account**: Execution uses a dedicated service account (`sa-ge-agent-extractor@agentspace-452714.iam.gserviceaccount.com`).
> - **Authenticated A2A Agent Card Probing**: Uses Google OIDC ID tokens (`Authorization: Bearer <id_token>`) when probing `.well-known/agent-card.json` endpoints on IAM-protected Cloud Run services.

---

## 📋 Prerequisites & Required IAM Roles

Ensure the service account `sa-ge-agent-extractor@agentspace-452714.iam.gserviceaccount.com` has the following GCP roles:

| GCP Role | Purpose |
| :--- | :--- |
| `roles/bigquery.dataEditor` | Insert extracted agent records into BigQuery. |
| `roles/bigquery.jobUser` | Execute BigQuery load/query jobs. |
| `roles/discoveryengine.admin` | Full list & read access across all Discovery Engine / Gemini Enterprise instances, engines, and registered assistants. |
| `roles/aiplatform.viewer` | Read Vertex AI Reasoning Engine metadata (ADK agents). |
| `roles/run.viewer` | Read Cloud Run agent services and deployment configurations via Python SDK. |
| `roles/run.invoker` | Allow Cloud Scheduler to invoke the Cloud Run job. |

## 🚀 Deployment Instructions

### Step 1: Clone Repository & Navigate to Project Directory
```bash
git clone https://github.com/caugusto/GE-Agent-Info-Extractor.git
cd GE-Agent-Info-Extractor
```

### Step 2: Enable GCP Service APIs
```bash
gcloud services enable \
    cloudbuild.googleapis.com \
    run.googleapis.com \
    cloudscheduler.googleapis.com \
    artifactregistry.googleapis.com \
    discoveryengine.googleapis.com \
    aiplatform.googleapis.com \
    bigquery.googleapis.com \
    --project=agentspace-452714
```

### Step 3: Create Service Account & Grant Roles
```bash
SA_EMAIL="sa-ge-agent-extractor@agentspace-452714.iam.gserviceaccount.com"

# Create Service Account
gcloud iam service-accounts create sa-ge-agent-extractor \
    --display-name="GE Agent Extractor Service Account" \
    --project=agentspace-452714

# Assign Roles
for ROLE in \
    "roles/bigquery.dataEditor" \
    "roles/bigquery.jobUser" \
    "roles/discoveryengine.admin" \
    "roles/aiplatform.viewer" \
    "roles/run.viewer" \
    "roles/run.invoker"; do
  gcloud projects add-iam-policy-binding agentspace-452714 \
      --member="serviceAccount:${SA_EMAIL}" \
      --role="${ROLE}" --condition=None
done
```

### Step 4: Build & Push Container Image
> [!NOTE]
> Execute this command from the **root directory** of the cloned repository (`GE-Agent-Info-Extractor/`) where the `Dockerfile` is located. The trailing dot (`.`) specifies the build context directory.

```bash
gcloud builds submit --tag gcr.io/agentspace-452714/ge-agent-extractor:latest .
```

### Step 5: Create Cloud Run Job
```bash
gcloud run jobs create ge-agent-inventory-job \
    --image gcr.io/agentspace-452714/ge-agent-extractor:latest \
    --service-account sa-ge-agent-extractor@agentspace-452714.iam.gserviceaccount.com \
    --region us-central1 \
    --tasks 1 \
    --max-retries 1 \
    --task-timeout 15m \
    --project agentspace-452714
```

### Step 6: Schedule Job Every 4 Hours
```bash
gcloud scheduler jobs create http ge-agent-inventory-4h \
    --schedule="0 */4 * * *" \
    --uri="https://us-central1-run.googleapis.com/apis/run.googleapis.com/v1/namespaces/agentspace-452714/jobs/ge-agent-inventory-job:run" \
    --http-method POST \
    --message-body='{"overrides":{"containerOverrides":[{"env":[{"name":"EXECUTION_SOURCE","value":"CLOUD_SCHEDULER"}]}]}}' \
    --headers="Content-Type=application/json" \
    --oauth-service-account-email sa-ge-agent-extractor@agentspace-452714.iam.gserviceaccount.com \
    --location us-central1 \
    --project agentspace-452714
```

## 🔍 Operations & Monitoring

```bash
# Manually trigger job execution
gcloud run jobs execute ge-agent-inventory-job --region=us-central1 --project=agentspace-452714

# List executions
gcloud run jobs executions list --job=ge-agent-inventory-job --region=us-central1 --project=agentspace-452714

# Read logs
gcloud logging read "resource.type=cloud_run_job AND resource.labels.job_name=ge-agent-inventory-job" --limit=50 --project=agentspace-452714
```
